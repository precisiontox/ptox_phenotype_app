Explore Endpoints

Select organism and endpoint to explore the data distribution, chemical ranking and dose-response curve for every chemical. The table at the bottom shows all individual records matching the current filters.

Choose options:

Organism

Select an organism.

Endpoint category

Endpoint

Select an endpoint.

Endpoint distribution ? Compares the distribution of values for the selected endpoint across all chemicals between controls and chemical exposures.

Chemical ranking

?
Ranks chemicals using a response summary metric for the selected endpoint. Only non-control numeric endpoint values are included. The options are:
  • Mean response: mean endpoint value across all tested concentrations for each chemical
  • Max. response: maximum recorded endpoint value across all tested concentrations for each chemical
  • Response at max. concentration: mean endpoint value at the highest tested concentration for each chemical

Dose-response curves ? Shows endpoint response against exposure concentration for the selected chemical, grouped by experiment batch and exposure duration.
Each line corresponds to a different experiment batch (for both exposures and controls).

Database records

All database records corresponding to the selected endpoint (and chemical if selected).
